# 魔方 DAM V1 视觉基准

## 概念图

- `asset-browser-concept.png`：1440 × 900 主资产界面。
- `connection-screen-concept.png`：1440 × 900 首次连接界面。

两张概念图是 V1 桌面端的实现基准，不作为应用中的静态界面图片使用。

## 设计系统

- 背景：深炭黑 `#101419`，面板 `#151a20`，抬升面 `#1b2128`。
- 文字：主文字 `#f3f5f7`，次文字 `#a6afb9`，弱文字 `#6f7985`。
- 强调：冷蓝 `#2f8cff`；成功状态 `#41d897`；危险状态 `#ef6b73`。
- 边框：`#2a323c`，默认 1px；圆角集中使用 8px 和 10px。
- 字体：Inter、Segoe UI、Microsoft YaHei 的系统回退栈；桌面工具栏 12–14px，内容标题 24px。
- 图标：统一 1.5px 描边、16–20px，选中态使用蓝色，未选中态使用冷灰。
- 容器：左侧目录树 238px；中间自适应；右侧详情 310px；底部状态栏 54px。
- 动效：120–180ms 的颜色、边框和位移过渡；遵循 `prefers-reduced-motion`。

## 可见文案锁

首屏允许出现的主要文案来自目标与概念图：魔方数字资产管理、资产库、文件夹、全部素材、回收站、操作日志、搜索文件和文件夹、新建文件夹、上传、全部类型、最近修改、文件详情、下载，以及当前真实文件夹/资产名称。不得加入营销文案、假指标或虚构资产。

## 组件边界

应用外壳、连接设置、目录树、工作区工具栏、资产网格/列表、文件详情、媒体预览、操作日志、上传队列、通用对话框与通知分别实现。React 状态只保存当前选择、筛选条件和瞬时交互；文件与目录来源始终为 Backend API。
